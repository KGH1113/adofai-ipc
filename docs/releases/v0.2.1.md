# AdofaiIpc Bootstrap 0.2.1

의존 모드용 bootstrap을 고정 dependency shim과 versioned candidate 구조로 전환했습니다.
missing 자동 설치는 유지하며, 설치 실패·비활성화·구버전·로드 실패를 여러 의존 모드가
공유하는 단일 retained-mode Unity uGUI로 안내합니다.

이 구조를 처음 포함하는 TUFReplay와 TUFHelperLite 릴리스는 각각 한 번 수동 재설치해야 합니다.
이후 bootstrap 후보는 모드 updater가 staging하며 다음 게임 실행에서 적용됩니다.
