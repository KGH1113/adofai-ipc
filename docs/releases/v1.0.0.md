# v1.0.0 preparation

Product1.0.0 uses wire protocol3 and a loopback WebSocket endpoint `/ipc/ws` with subprotocol
`adofai-ipc.v3`. Both peers send commands and reply with named events; subscriptions receive
namespace lifecycle and domain snapshots/changes. HTTP RPC, method discovery, generic call
results and status polling are removed. Consumer domain protocols must be migrated together.

The runtime embeds a pinned, namespace-isolated managed WebSocket implementation compatible
with ADOFAI's Mono runtime. Message/frame, queue, peer and command limits protect frame time and
memory. Command tokens follow connection/namespace lifetime. Same-process local peers use the
same router. Downloads remain bounded HTTP streams behind single-use tickets.

The TypeScript SDK exposes message channels and an injectable transport port with reconnect
and resubscribe, without command replay. Consumers vendor raw source with commit/hash provenance.
No npm publish, public release or release tag is created during this preparation.

Validation uses `./scripts/run.sh check`, `build`, `client`, and `package`, including actual
WebSocket C#↔SDK communication, readiness, named correlation, reverse commands, authorization,
download streaming, deduplication, cancellation and reconnect.
