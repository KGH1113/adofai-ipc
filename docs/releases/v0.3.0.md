# AdofaiIpc v0.3.0

AdofaiIpc 0.3.0 introduces the shared dependency bootstrap and lockstep web client version policy.

- Dependent mods now use one retained-mode dependency error UI for missing, disabled, outdated, and load-failure states.
- Official AdofaiIpc 0.2.0 is treated as outdated by dependent mods requiring 0.3.0; their core is not loaded until AdofaiIpc is manually updated and the game is restarted.
- `/ipc/health` exposes `serverVersion`.
- `@adofai-ipc/client` requires an exact product-version match and reports a typed `IpcVersionMismatchError`.
- The mod, dependency bootstrap, npm client, Git tag, GitHub release, and packaged metadata are released as the same product version.
- AdofaiIpc now starts through a fixed shim. Stable updates are downloaded, validated, and loaded before the dependent mods in the same game launch.
- TUFReplay beta.9 and TUFHelperLite 0.1.3 carry one shared migration helper and show a single restart/reinstall dialog without starting their features.

For the first migration, existing users reinstall only AdofaiIpc 0.3.0 and fully restart the game.
