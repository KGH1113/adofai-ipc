# AdofaiIpc v0.3.0

AdofaiIpc 0.3.0 introduces a fixed shim and versioned launcher/runtime layout. Stable updates are
downloaded and verified without replacing loaded DLLs, then activated on the next game launch.

## 주요 변경사항

- `Info.json`이 고정 `AdofaiIpc.Shim.dll`을 로드
- `Update/state.json`의 current, previous, trial 상태를 이용한 원자적 활성화와 rollback
- package size, SHA-256, metadata, required files, ZIP 경로와 해제 크기 검증
- 한 프로세스의 single-flight와 파일 잠금을 통한 중복 설치 방지
- `AdofaiIpc.update.json` 안정판 manifest 제공
- dependency bootstrap 설정을 `UpdateManifestUrl` 기반으로 변경

기존 0.2.0 이하 설치는 전환 bridge가 runtime을 보존하고 0.3.0을 trial로 staging합니다.
현재 실행에서는 기존 DLL을 계속 사용하고, 게임을 한 번 완전히 종료한 뒤 다시 실행하면
0.3.0 후보가 활성화됩니다.
