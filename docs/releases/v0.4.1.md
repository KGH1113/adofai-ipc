# AdofaiIpc v0.4.1

AdofaiIpc 0.4.1 fixes startup on ADOFAI installations whose custom or merged `0Harmony.dll` exposes `DefaultInterpolatedStringHandler`. The 0.4.0 runtime could compile string interpolation against that Harmony implementation; on affected Mono runtimes, `IpcServer.StartListener()` then failed with `MethodAccessException` before the local IPC listener started.

The runtime no longer references `0Harmony.dll`, and its startup path avoids the string-handler lowering. Build and package workflows now reject shipped assemblies that reference `DefaultInterpolatedStringHandler`. Streaming downloads and the IPC protocol are unchanged.

The npm client checks the server's exact product version. Use `@adofai-ipc/client` 0.4.1 with the 0.4.1 mod; a 0.4.0 client will report a version mismatch. Install `AdofaiIpc.zip` into the game's `Mods` directory and fully restart the game. Verify the archive with `AdofaiIpc.zip.sha256` before installing it.
