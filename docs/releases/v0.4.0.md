# AdofaiIpc v0.4.0

AdofaiIpc 0.4.0 adds streamed downloads to the existing localhost IPC listener. Mods can register a download method that returns a short-lived ticket, and browsers can open its URL to save a file without buffering it in JavaScript memory. The response body is written from a stream or callback on an HTTP worker.

- Download tickets expire after 60 seconds, can be used once, and are revoked when their namespace is unregistered or the server stops.
- The server limits pending tickets and concurrent downloads. Namespace origin rules apply when tickets are created and when download requests include an Origin header.
- Existing JSON IPC methods and the client connection API remain available. `@adofai-ipc/client` 0.4.0 performs the same exact product-version check as 0.3.0, so the mod and npm client must be updated together.
- The ZIP includes the dependency bootstrap, shim, migration helper, and versioned runtime. Dependent mods that require 0.4.0 must package the matching 0.4.0 bootstrap artifacts.

See the [streaming download guide](../en/007-Downloads.md) for registration and browser usage. Install `AdofaiIpc.zip` from this release into the game's `Mods` directory, then fully restart the game. Verify the archive with `AdofaiIpc.zip.sha256` before installing it.
