브라우저에서 모드의 표시 문구와 활성 여부를 조회하고 변경하는 프로젝트를 만듭니다. 먼저 조회 기능을 완성하고, 그 위에 저장 기능을 추가합니다.

설정은 모드 메모리에 보관합니다. 브라우저를 새로고침해도 유지되지만 모드를 재활성화하면 초기값으로 돌아갑니다.

## 진행 순서

| 단계 | 추가할 내용 | 확인할 결과 |
| --- | --- | --- |
| [1. 프로젝트와 계약 준비](/examples/settings/setup/) | 폴더, 빈 화면, 조회 계약 | 브라우저에 비활성 입력란 표시 |
| [2. 모드 등록](/examples/settings/mod/) | 모드의 초기 설정과 조회 handler | 모드 활성화 시 IPC 기능 등록 |
| [3. 브라우저에서 조회](/examples/settings/read/) | 앱 등록과 `getSettings()` 호출 | 모드의 초기값이 화면에 표시 |
| [4. 저장 기능 추가](/examples/settings/write/) | 계약·모드·앱에 저장 기능 추가 | 저장한 값을 새로고침 후에도 조회 |

각 페이지는 **이번 단계의 목표 → 파일 변경 → 실행 결과** 순서로 진행합니다. 앞 단계의 코드를 이어서 수정하며, diff의 `+`는 추가할 줄, `-`는 제거할 줄입니다.

## 시작 조건

- C# 모드 프로젝트에 IPC SDK가 참조되어 있고, 활성화 콜백에서 SDK 객체 `ipc`를 사용할 수 있어야 합니다.
- TypeSpec에서 TypeScript·C# 코드를 생성할 설정이 필요합니다. 출력 연결은 [코드 생성과 모노레포](/guides/monorepo/)를 따릅니다.
- 웹 앱은 Node.js와 pnpm을 사용합니다. 모드의 활성화·비활성화 콜백은 사용하는 모드 프레임워크의 수명에 연결합니다.
