앱은 `adofai-ipc`와 계약에서 생성한 패키지를 참조합니다. 아래 `@example/ipc`는 생성 패키지의 예제 이름입니다.

## 등록과 모드 호출

`registerApp()`으로 앱을 등록하고 `use()`로 계약을 선택합니다. 아래 계약은 `op echo(text: string): string;`입니다.

```ts
import { ipc } from "adofai-ipc";
import { EchoContract } from "@example/ipc";

const app = ipc.registerApp({ displayName: "Echo UI" });

try {
  const channel = app.use(EchoContract, {});
  await channel.ready();
  console.log(await channel.echo({ text: "hello" }));
} catch (error) {
  console.error("호출 실패", error);
} finally {
  app.dispose();
}
```

| API·인자 | 반환값·동작 |
| --- | --- |
| `registerApp({ displayName })` | 앱 등록 객체. 이름은 사용자에게 표시할 문자열 |
| `use(contract, handlers)` | 생성된 모드 메서드를 제공하는 채널 |
| `ready()` | 모드 준비와 앱 등록 완료를 기다리는 `Promise<void>` |
| `echo({ text })` | 모드 handler의 결과인 `Promise<string>` |
| `dispose()` | 앱 등록과 계약 사용 해제. 반환값 없음 |

앱 ID는 UUID로 자동 생성합니다. 같은 등록의 재연결에서는 유지하고 새 탭·새 등록에는 다른 ID를 부여합니다. ID와 표시 이름은 접근 권한을 부여하지 않습니다.

지속 실행하는 앱은 진입점에서 등록을 만들고 종료 시 해제합니다. React에서는 `useEffect()`에서 등록하고 cleanup에서 `app.dispose()`를 호출합니다. 호출할 때마다 등록을 새로 만들 필요는 없습니다.

## 앱 메서드 제공

`use()`의 두 번째 인자에 앱 handler를 전달합니다. 다음 예제는 `confirm(message: string): boolean;`을 제공하는 `DialogsContract`입니다.

```ts
import { ipc } from "adofai-ipc";
import { DialogsContract } from "@example/ipc";

const app = ipc.registerApp({ displayName: "Dialog UI" });

app.use(DialogsContract, {
  confirm: ({ message }) => window.confirm(message),
});

// 앱 종료 시 app.dispose()를 호출합니다.
```

`message`는 `string`으로 추론됩니다. handler는 `boolean` 또는 `Promise<boolean>`을 반환해야 합니다. 필수 handler가 없거나 반환 타입이 다르면 타입 오류입니다. 앱 메서드가 없는 계약은 `{}`를 전달합니다.

호출 오류·재시도 조건은 [동작 규칙](/docs/reference/lifecycle/)을 참고하세요.

## 재연결과 상태 조회

`onStatus()`는 현재 상태를 즉시 전달하고 이후 변경도 알립니다. `ready`는 앱의 재등록이 끝난 상태이므로 초기 연결과 재연결에서 snapshot을 조회할 수 있습니다.

```ts
const stop = channel.onStatus((status, error) => {
  if (status === "ready") {
    void channel.getSettings().then(showSettings).catch(showError);
  } else if (error) {
    showError(error);
  }
});

// 화면 해제 시
stop();
app.dispose();
```

이 예제는 `getSettings()`가 있는 채널에서 결과를 `showSettings()`에 전달합니다. 상태는 `unavailable`, `initializing`, `ready`, `error`이며 `channel.status`로도 읽습니다. `channel.sessionId`는 등록 후에만 존재하고 재연결하면 바뀝니다. 앱 handler로 받는 변경 알림과 재연결 snapshot을 함께 사용합니다.
