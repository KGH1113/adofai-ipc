创建一个项目，在浏览器中读取和修改模组的显示文本与启用状态。先完成读取功能，再添加保存功能。

设置保存在模组内存中。刷新浏览器后仍会保留，但重新启用模组时会恢复初始值。

## 步骤

| 步骤 | 添加内容 | 预期结果 |
| --- | --- | --- |
| [1. 准备项目与契约](/docs/zh-cn/examples/settings/setup/) | 目录、空白页面与读取契约 | 浏览器显示禁用的输入控件 |
| [2. 注册模组](/docs/zh-cn/examples/settings/mod/) | 初始设置与读取处理器 | 启用模组时注册 IPC 功能 |
| [3. 在浏览器中读取](/docs/zh-cn/examples/settings/read/) | 注册应用并调用 `getSettings()` | 页面显示模组的初始值 |
| [4. 添加保存功能](/docs/zh-cn/examples/settings/write/) | 为契约、模组和应用添加保存功能 | 刷新浏览器后仍能读取保存的值 |

每一页按**本步目标 → 文件修改 → 预期结果**的顺序展开，并在上一步代码的基础上继续修改。diff 中的 `+` 表示添加的行，`-` 表示删除的行。

## 前提条件

- C# 模组项目已经引用 IPC SDK，并且在启用回调中可以访问 SDK 对象 `ipc`。
- 已配置从 TypeSpec 生成 TypeScript 和 C# 代码。输出引用方式请参阅[代码生成与仓库结构](/docs/zh-cn/guides/monorepo/)。
- 网页应用使用 Node.js 和 pnpm。模组的启用与停用回调应接入所用模组框架的生命周期。
