ADOFAI IPC는 A Dance of Fire and Ice의 C# 모드와 같은 컴퓨터에서 실행되는 브라우저 앱 사이의 양방향 통신을 지원하는 라이브러리입니다.

모드와 앱은 TypeSpec 계약에서 생성한 C#·TypeScript API로 서로의 메서드를 호출합니다. 모드는 계약과 접근 정책을 관리하며, IPC는 데이터 변환과 연결 관리를 처리합니다.
