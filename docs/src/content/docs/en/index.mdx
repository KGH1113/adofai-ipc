ADOFAI IPC is a library for bidirectional communication between C# mods for A Dance of Fire and Ice and browser apps running on the same computer.

Mods and apps call each other's methods through C# and TypeScript APIs generated from a TypeSpec contract. The mod manages the contract and access policy; IPC handles data conversion and connection management.
