이번 단계에서는 **입력란만 있는 화면과 설정 조회 계약**을 만듭니다. 아직 통신 코드는 추가하지 않습니다. 빈 화면이 열리는 것부터 확인합니다.

## 프로젝트 구성

모드·앱·계약을 같은 저장소에 둡니다. C# 모드의 SDK 참조와 활성화·비활성화 콜백은 준비되어 있다고 가정합니다.

```text
apps/mod/                  # C# 모드
apps/web/                  # 브라우저 앱
packages/contracts/main.tsp # 계약 원본
packages/ipc/              # 생성된 TypeScript 패키지
```

저장소 루트에서 [Vite TypeScript 앱](https://vite.dev/guide/#scaffolding-your-first-vite-project)을 만들고 workspace에 포함합니다.

```bash
pnpm create vite apps/web --template vanilla-ts
```

```yaml title="pnpm-workspace.yaml"
packages:
  - apps/web
  - packages/*
```

## 빈 설정 화면

템플릿의 `index.html`을 교체합니다. 조회 전에는 빈 값을 수정하지 못하도록 입력을 잠급니다. 저장 버튼은 마지막 단계에서 추가합니다.

```html title="apps/web/index.html"
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="utf-8" />
    <title>모드 설정</title>
  </head>
  <body>
    <form id="settings">
      <fieldset disabled>
        <label>표시 문구 <input id="label" /></label>
        <label><input id="enabled" type="checkbox" /> 활성화</label>
      </fieldset>
      <output id="status" aria-live="polite"></output>
    </form>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>
```

`src/main.ts`의 템플릿 코드도 아래 내용으로 교체합니다. `export {}`는 이 파일을 TypeScript 모듈로 취급하게 합니다.

```ts title="apps/web/src/main.ts"
export {};

const status = document.querySelector<HTMLOutputElement>("#status")!;
status.textContent = "모드 연결 전";
```

## 조회 계약

화면에 표시할 두 필드와 조회 메서드를 정의합니다. 값은 모드가 관리하며 앱은 그 결과를 표시합니다.

```typespec title="packages/contracts/main.tsp"
import "@adofai-ipc/typespec";

@ipc.mod("settings-example")
namespace SettingsExample {
  model Settings {
    label: string;
    enabled: boolean;
  }

  op getSettings(): Settings;
}
```

이 계약에서 TypeScript 패키지를 `packages/ipc/`, C# 소스를 `apps/mod/Generated/`로 생성합니다. 생성되는 `SettingsExampleContract`는 양쪽 등록에, `Settings`는 조회 결과에 사용합니다.

[코드 생성과 모노레포](/guides/monorepo/#생성과-참조)의 설정에서 C# namespace를 `SettingsExample.Generated`로 지정하고 `pnpm exec adofai-ipc generate`를 실행합니다. 앱에는 `adofai-ipc`와 `"@example/ipc": "workspace:*"`를 의존성으로 추가합니다. C# 생성 소스는 모드와 함께 컴파일합니다.

## 확인

루트에서 `pnpm install`을 실행한 뒤 `apps/web`에서 개발 서버를 실행합니다.

```bash
pnpm dev --host localhost --port 5173 --strictPort
```

`http://localhost:5173`에 **빈 입력란, 해제된 체크박스, `모드 연결 전`**이 표시되면 준비가 끝났습니다. 포트는 다음 단계의 `allowedOrigins`와 일치해야 합니다.
